## 🏛️ 1. Корпоративная иерархия холдинга «Фаровон»

Схема оргструктуры (`public/index.html` → блок `renderAdminOrg`) построена по 4-ярусной модели корпоративного управления:

```
                  ┌─────────────────────────────────┐
                  │    Ярус 0: Farovon Holding      │
                  │       (Группа компаний)         │
                  └────────────────┬────────────────┘
                                   │
                  ┌────────────────┴────────────────┐
                  │   Ярус 1: Совет директоров      │
                  │      (Бобочонов Баходур)        │
                  └────────────────┬────────────────┘
                                   │
              ┌────────────────────┴────────────────────┐
              ▼                                         ▼
┌───────────────────────────┐             ┌───────────────────────────┐
│ Ярус 2 (Центр): Правление │             │  Ярус 2 (Бок): Служба     │
│    (Бобочонов Баходур)    │             │   внутреннего аудита      │
│  [Исполнительный орган]   │             │   (Рабиев Илхомджон)      │
└─────────────┬─────────────┘             │     [Контроль СД]         │
              │                           └───────────────────────────┘
              ▼
┌─────────────────────────────────────────────────────────────────────┐
│ Ярус 3: 24 Линейных операционных департамента / направления         │
│ (АХУ — Мирзомансуров А., Производство, Снабжение, Финансы, HR и др.)│
└─────────────────────────────────────────────────────────────────────┘
```

### Ключевые правила сопоставления органов управления:
* **Строгие предикаты (`public/index.html`):**
  * `isBoardName`: строго `'совет директоров'` или `'совет директора'` (не путать с линейными директорами).
  * `isExecName`: строго `'правление'` или `'правление компании'` (строгое равенство, чтобы «Административно-хозяйственное **управление**» не попадало в Правление).
  * `isAuditName`: содержит `'аудит'` (Служба внутреннего аудита с бейджем `Контроль СД`).
* **Руководители верхушки:**
  * Совет директоров: **Бобочонов Баходур**
  * Правление компании: **Бобочонов Баходур**
  * Служба внутреннего аудита: **Рабиев Илхомджон**
  * АХУ (Административно-хозяйственное управление): **Мирзомансуров Абдурахмон** (линейный департамент на Ярусе 3).

## 🌳 3. Конструктор оргструктуры и Drag-and-Drop (до 5 уровней)

* **Уровень 1 (Governance):** Farovon Holding → Совет директоров → Правление + Аудит.
* **Уровень 2 (Directions):** 24 линейных направления (`dir`).
* **Уровень 3 (Units):** Отделы внутри выбранного направления (`unit`, `parent_unit = NULL`).
* **Уровень 4 (Subunits L4):** Подотделы внутри отдела (`parent_unit = <unit_L3>`).
* **Уровень 5 (Subunits L5):** Подотделы 5-го порядка (`parent_unit = <unit_L4>`).
* **Интерактивность:**
  * Клик по любой карточке раскрывает подчиненные ветки и правую панель состава (`orgDrawer`).
  * Перетаскивание карточки отдела на карточку другого отдела делает его подотделом.
  * Перетаскивание на карточку направления переносит отдел в это направление (сбрасывая `parent_unit`).
  * Кнопка **«↩ Отменить»** (`pushUndo` / `popUndo`) локально откатывает ошибочные переносы без порчи чужих данных.

## 🗄️ 4. База данных Turso LibSQL и безопасность данных

* **Центральная БД:** Turso LibSQL Cloud (`libsql://...` в AWS Frankfurt).
* **Сквозная синхронизация:**
  * Все операции перетаскивания и назначения пишутся в базу через API в реальном времени.
  * Назначение ответственного (`saveDivision`) автоматически обновляет поле `unit` в таблице `users`.
* **Безопасность:**
  * Администратор `admin` защищен от удаления и понижения роли.
  * Миграции в `src/db/migrate.js` строго идемпотентны (`IF NOT EXISTS`, `ensureColumn`).
