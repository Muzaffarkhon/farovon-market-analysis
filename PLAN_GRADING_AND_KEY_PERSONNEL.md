## 1. ЦЕЛИ И АРХИТЕКТУРНЫЙ ЗАМЫСЕЛ

Интеграция двух ключевых управленческих инструментов напрямую в единую систему C&B холдинга:
1. **Модуль грейдирования должностей (Job Grading Module):** Оценка требований к функции (роли) без привязки к личности по 4 дифференцированным функциональным группам для 15 направлений бизнеса холдинга.
2. **Модуль оценки рисков незаменимости персонала (Key Personnel Risk Matrix):** Оценка уязвимости бизнеса перед уходом уникальных носителей знаний (Bus Factor, срок замены, монополия на информацию, цена ошибки) для формирования кадрового резерва и наставничества.

## 2. СХЕМА БАЗЫ ДАННЫХ (SQLite / LibSQL)

В базу данных проекта добавляются две новые связанные таблицы и индексы.

```sql
-- Таблица 1: Оценка и грейдирование должностей
CREATE TABLE IF NOT EXISTS job_evaluations (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  unit TEXT NOT NULL,                         -- Подразделение / Завод из справочника divisions
  job_title TEXT NOT NULL,                    -- Наименование должности
  group_type TEXT NOT NULL,                   -- 'production', 'auxiliary', 'sales', 'aup'
  factor_1 INTEGER NOT NULL CHECK(factor_1 BETWEEN 1 AND 5),
  factor_2 INTEGER NOT NULL CHECK(factor_2 BETWEEN 1 AND 5),
  factor_3 INTEGER NOT NULL CHECK(factor_3 BETWEEN 1 AND 5),
  factor_4 INTEGER CHECK(factor_4 IS NULL OR factor_4 BETWEEN 1 AND 5), -- Для производства 4 фактора, для остальных 3
  weighted_score REAL NOT NULL,               -- Итоговый взвешенный балл (1.00 - 5.00)
  grade_level INTEGER NOT NULL,               -- Рассчитанный грейд (1 - 6)
  evaluated_by TEXT NOT NULL,                 -- ФИО эксперта / login пользователя
  notes TEXT,                                 -- Обоснование оценки комиссии
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_job_eval_unit ON job_evaluations(unit);
CREATE INDEX IF NOT EXISTS idx_job_eval_title ON job_evaluations(job_title);

-- Таблица 2: Оценка рисков незаменимости ключевого персонала
CREATE TABLE IF NOT EXISTS key_personnel_risks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  unit TEXT NOT NULL,                         -- Подразделение / Завод
  employee_fio TEXT NOT NULL,                 -- ФИО оцениваемого сотрудника
  job_title TEXT NOT NULL,                    -- Должность
  bus_factor INTEGER NOT NULL CHECK(bus_factor BETWEEN 1 AND 5),         -- Незаменимость
  replacement_time INTEGER NOT NULL CHECK(replacement_time BETWEEN 1 AND 5), -- Срок замены
  knowledge_monopoly INTEGER NOT NULL CHECK(knowledge_monopoly BETWEEN 1 AND 5), -- Оцифровка знаний
  financial_risk INTEGER NOT NULL CHECK(financial_risk BETWEEN 1 AND 5),   -- Цена ошибки / простоя
  total_risk_score INTEGER NOT NULL,          -- Сумма баллов (4 - 20)
  risk_status TEXT NOT NULL,                  -- 'standard', 'attention', 'critical'
  action_plan TEXT NOT NULL,                  -- Рекомендуемое решение (дублер, регламент и т.д.)
  evaluator_user_id INTEGER,                  -- ID руководителя, заполнившего анкету
  evaluator_fio TEXT NOT NULL,                -- ФИО руководителя
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_key_personnel_unit ON key_personnel_risks(unit);
CREATE INDEX IF NOT EXISTS idx_key_personnel_status ON key_personnel_risks(risk_status);
```

## 3. БИЗНЕС-ЛОГИКА И МАТЕМАТИКА РАСЧЁТА

### 3.1. Грейдирование должностей (Веса факторов)

* **Группа 1: Производственный персонал (Шкала 6 → 1):**
  $$\text{Балл} = (\text{П1} \times 0.30) + (\text{П2} \times 0.30) + (\text{П3} \times 0.25) + (\text{П4} \times 0.15)$$
* **Группа 2: Вспомогательный персонал (Шкала 6 → 1):**
  $$\text{Балл} = (\text{В1} \times 0.40) + (\text{В2} \times 0.30) + (\text{В3} \times 0.30)$$
* **Группа 3: Торговый персонал (Шкала 5 → 1):**
  $$\text{Балл} = (\text{Т1} \times 0.50) + (\text{Т2} \times 0.30) + (\text{Т3} \times 0.20)$$
* **Группа 4: АУП (Шкала 5 → 1):**
  $$\text{Балл} = (\text{А1} \times 0.40) + (\text{А2} \times 0.40) + (\text{А3} \times 0.20)$$

#### Таблица соответствия баллов грейдам:
| Диапазон баллов | Производство / Вспомогательный | Торговый / АУП |
|:---:|:---:|:---:|
| $1.00 - 1.69$ | **Уровень 6** | — |
| $1.70 - 2.49$ | **Уровень 5** | **Уровень 5** |
| $2.50 - 3.29$ | **Уровень 4** | **Уровень 4** |
| $3.30 - 3.99$ | **Уровень 3** | **Уровень 3** |
| $4.00 - 4.59$ | **Уровень 2** | **Уровень 2** |
| $4.60 - 5.00$ | **Уровень 1** | **Уровень 1** |

---

### 3.2. Матрица уязвимости ключевого персонала

$$\text{Индекс риска} = \text{Bus Factor} + \text{Срок замены} + \text{Монополия на знания} + \text{Финансовый риск}$$

* **4 – 8 баллов:** `🟢 Штатный сотрудник (standard)`  
  *Решение:* Рисков нет, замена доступна в рабочем порядке.
* **9 – 13 баллов:** `🟡 Зона внимания (attention)`  
  *Решение:* Необходима плановая регламентация, составление карт наладки/инструкций.
* **14 – 20 баллов:** `🔴 КРИТИЧЕСКИЙ РИСК НЕЗАМЕНИМОСТИ (critical)`  
  *Решение:* Срочно назначить официального дублера + соглашение о наставничестве на 3–6 месяцев с временной персональной надбавкой. После аттестации дублера надбавка снимается.

## 4. REST API ЭНДПОИНТЫ ДЛЯ СЕРВЕРА

В файл `src/routes/api.js` добавляется новый контроллер:

### Раздел «Грейдирование»:
* `GET /api/grading/positions` — получение реестра уникальных должностей и их текущих грейдов.
* `POST /api/grading/evaluate` — сохранение оценки комиссии по должности.
* `GET /api/grading/stats` — сводная статистика распределения должностей по уровням (1–6).

### Раздел «Оценка ключевого персонала»:
* `GET /api/key-personnel/list` — получение списка оценок с фильтрацией по заводу/подразделению и статусу риска.
* `POST /api/key-personnel/evaluate` — отправка оценки по сотруднику руководителем.
* `GET /api/key-personnel/heatmap` — тепловая карта рисков по 15 направлениям для Правления.

## 5. ПОЛЬЗОВАТЕЛЬСКИЙ ИНТЕРФЕЙС (UI/UX В SPA)

1. **Главная навигация (боковое меню):**
   - Добавляются два новых пункта меню с правами доступа (`admin`, `cb`, `hrbp`, `dir_head`):
     - 📊 **Грейдирование должностей**
     - 🛡️ **Риски ключевого персонала**
2. **Форма оценки должности:**
   - Выбор завода и должности из выпадающего списка с автопоиском.
   - Переключатель группы (Производство / Вспомогательный / Торговля / АУП).
   - Интерактивные карточки с подробным описанием всех 5 баллов по каждому фактору.
   - Живой предпросмотр: балл и грейд рассчитываются на лету прямо при клике на вариант ответа!
3. **Карточка оценки ключевого сотрудника:**
   - ФИО, должность, цех.
   - 4 вопроса с понятными радиокнопками 1..5.
   - Динамический спидометр/индикатор риска: мгновенная смена цвета (зеленый $\rightarrow$ желтый $\rightarrow$ красный) при заполнении.
4. **Тепловая карта рисков для C&B и Правления:**
   - Сводная таблица по 15 направлениям бизнеса: сколько в каждом дивизионе выявлено сотрудников с критическим риском незаменимости.
