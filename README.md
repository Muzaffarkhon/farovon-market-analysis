# 📊 Farovon Market Analysis & C&B Salary Benchmarking

> **Система анализа рынка, конкурентных карт и заработных плат C&B Фаровон**  
> Автономный full-stack сервис на **Node.js / Express / SQLite** с встроенным **Telegram Mini App WebApp SPA**, аналитическим дашбордом зарплатных вилок и панелью администратора.

---

## 🚀 Возможности системы

### 1. 🏢 Модуль сбора данных (326 подразделений)
- Актуализация списка конкурентов («Актуально» / «Не актуально» / «Уточнить»).
- Сбор данных по рынку: оклады (вилка От–До), периодичность, премии (тип, размер, период), льготы и бенефиты, надёжность источника.
- Умный поиск и пополнение справочников должностей и компаний.
- Автосохранение черновиков на устройстве при обрыве связи.

### 2. 📈 Аналитический Дашборд C&B
- **Перцентильный анализ**: автоматический расчёт **Min, P25, Median (P50), P75, Max** и размаха вилки в `%`.
- **Визуализация Box-Plot**: горизонтальные интерактивные шкалы распределения зарплат.
- **Детализация по компаниям**: сравнение окладов и соцпакетов в разрезе конкретных работодателей.
- **Воронка охвата**: мониторинг статусов заполнения по HR BP и Дирекциям.
- **Рейтинг льгот и бонусов**: популярность льгот (ДМС, питание, связь, ГСМ) и структуры премирования.
- **Экспорт в CSV**: выгрузка готового аналитического среза в 1 клик.

### 3. ⚙️ Панель Администратора
- **Управление пользователями**: добавление, редактирование, сброс паролей, блокировка/разблокировка, привязка подразделений.
- **Оргструктура (326 отделов)**: оперативное назначение руководителей, ответственных за обзор и HR BP.
- **Период сбора**: открытие/закрытие кампаний опроса с контролем прав на редактирование.
- **Сервисные утилиты**: нормализация сегментов и дублей, проверка связей, пересчёт статусов.
- **Audit Log**: аудит всех действий пользователей в системе в реальном времени.

### 4. 🤖 Прямой Telegram Bot & WebApp
- Поддержка Telegram WebApp SDK (автоматическая адаптация под темную/светлую тему Telegram).
- Авторизация через Telegram.
- Массовая рассылка персональных напоминаний должникам.

## 🛠️ Установка и локальный запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Muzaffarkhon/farovon-market-analysis.git
cd farovon-market-analysis
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка переменных окружения
Создайте файл `.env` на основе `.env.example`:
```env
PORT=3000
NODE_ENV=development
JWT_SECRET=your_super_secret_jwt_key
DATABASE_PATH=./data/market.db
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
WEBAPP_URL=http://localhost:3000
```

### 4. Сидирование базы данных (при первом запуске)
```bash
npm run seed
```
*База данных SQLite автоматически наполнится 326 подразделениями, связями, пользователями и справочниками из CSV.*

### 5. Запуск сервера
```bash
# Режим разработки с автоперезагрузкой:
npm run dev

# Продакшн режим:
npm start
```
Сервер будет доступен по адресу: `http://localhost:3000`

## 📡 REST API Справочник

### Аутентификация
- `POST /api/auth/login` — вход по логину и паролю
- `GET /api/auth/resume` — проверка и продление сессии
- `POST /api/auth/change-password` — смена пароля пользователя
- `POST /api/auth/set-units` — закрепление подразделений за пользователем

### Опрос и данные
- `POST /api/survey/save` — сохранение актуализации конкурентов
- `POST /api/survey/save-details` — сохранение анкет по должностям
- `POST /api/survey/dictionary/add` — добавление компании или должности в справочник

### Дашборд C&B
- `POST /api/dashboard/extended` — полная статистика рынка с перцентилями (Min, P25, Median, P75, Max)
- `POST /api/dashboard/hrbp` — статус заполнения по подразделениям
- `GET /api/dashboard/export-csv` — экспорт данных в CSV

### Панель Администратора (роли: `admin`, `cb`)
- `GET /api/admin/users` — список всех пользователей
- `POST /api/admin/users` — создание / редактирование пользователя
- `POST /api/admin/users/:login/toggle` — блокировка / активация
- `POST /api/admin/users/:login/reset-password` — сброс пароля
- `GET /api/admin/divisions` — оргструктура 326 подразделений
- `POST /api/admin/divisions` — назначение ответственных
- `POST /api/admin/period` — открытие / закрытие периода сбора
- `POST /api/admin/maintenance` — запуск сервисных утилит
- `GET /api/admin/audit-log` — журнал действий
