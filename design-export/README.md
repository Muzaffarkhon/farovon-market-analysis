## Как использовать с Claude Code
Положите папку `design-export/` в репозиторий (например в корень или в `docs/design/`) и укажите Claude Code: «Сверь экраны index.html с макетами в design-export/*.png по номерам turn и перенеси стиль/разметку; обновлённые public/style.css и public/index.html в этой же папке — образец применённого CSS-патча».
