# Опись экранов и действий перед переделкой дизайна

Составлена 2026-09-21 по версии 2.5.101. После переделки каждый экран сверяется с этим списком: ничего не должно пропасть.

## Навигация (зависит от роли и прав)

Основное меню: Главная; Отчёт по подразделениям; Подразделения; Дашборд (Обзор, Зарплатные вилки, По регионам, Реестр данных, Прогресс по HR BP, Льготы и Бонусы); Бенчмаркинг (Сравнение по должности, Сопоставление должностей, Источники и датасеты); Оценка должностей (Оценка должностей, Сводка по грейдам, Анкеты оценки, Блоки грейдирования); Оценка сотрудника (Ключевые сотрудники, Тепловая карта рисков); Сводка по HR BP (роль HR BP); Назначить ответственных (роль руководителя направления); Поддержка (обычные пользователи).

Администрирование: Пользователи (Все пользователи, Архив); Оргструктура; Справочники (Компании, Должности, Сегменты, Регионы, Подразделения, Сотрудники); Период сбора; Сервисные утилиты; Журнал действий; Поддержка; Рассылка; Роли и доступы.

Служебное: вкладки-окна с кнопкой «+», поиск по системе, обновить данные, Помощь, профиль, выход, выбор периода, светлая и тёмная тема, нижняя панель на телефоне.
