# План реализации: этап 7 (Telegram-бот)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Единая постоянная reply-клавиатура; идемпотентность вебхука по
`update_id`; проверка подписи `initData` + автовход через Mini App;
`sendMassReminder` переписан на `coordinationService` вместо упразднённого
`competitors.actual`; ежедневный планировщик напоминаний на Vercel Cron.

**Architecture:** Почти целиком серверный этап
(`src/services/telegramService.js`, `src/controllers/telegramController.js`,
новый `src/services/reminderService.js`, новый маршрут
`POST /api/cron/reminders`, новый маршрут `POST /auth/telegram`). Единственная
правка в `web/` — bootstrap-хук автовхода по `initData`.

**Tech Stack:** тот же, что в этапах 0–6. Криптография — встроенный `node:crypto`
(`timingSafeEqual`, `createHmac`), без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-09-24-react-bot-design.md`.

## Global Constraints

- Не трогаем вебхук-секрет (`safeEqual`/`timingSafeEqual` в
  `telegramController.js:465-478`) — уже корректен.
- Не трогаем `setMyCommands` (двойной scope — уже осознанный фикс, не баг).
- Не трогаем `/link`, `/login`, вход по диплинку/телефону — только
  добавляем параллельный путь входа через Mini App, ничего не меняя в
  существующем.
- Вся работа по вебхуку и по cron-обработчику — строго до `res.end()`
  (заморозка функции на Vercel сразу после ответа).
- `coordinationService.getCoordination` — переиспользуем, не копируем его
  SQL повторно в `reminderService`.

## Карта файлов

- `src/services/telegramService.js` — `mainReplyKeyboard()`, `verifyInitData()`,
  переписанный `sendMassReminder()`
- `src/controllers/telegramController.js` — рассылка клавиатуры вместо
  `REMOVE_KEYBOARD`, дедуп вебхука
- `src/controllers/authController.js` — `exports.telegramLogin`
- `src/controllers/broadcastController.js` — fallback https/http (мелкий фикс)
- `src/services/reminderService.js` — новый
- `src/controllers/cronController.js` — новый (`POST /api/cron/reminders`)
- `src/db/migrate.js` — таблицы `telegram_updates`, `reminder_log`
- `src/routes/api.js` — `/auth/telegram`, `/cron/reminders`
- `src/config/index.js` — `cronSecret`
- `vercel.json` — `crons`
- `web/src/api/auth.ts`, `web/src/app/` — bootstrap-хук автовхода
