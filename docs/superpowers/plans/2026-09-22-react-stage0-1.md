# План реализации: новый клиент на React, этапы 0–1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поднять новый React-клиент рядом со старым по адресу `/new` и закрыть на нём этапы 0 (вход, оболочка, дизайн-система, матрица ролей) и 1 (сбор данных одним листом с добавлением компаний, отметкой «не с кем», прогрессом по должностям и смежными группами), плюс точечные правки сервера из спеки.

**Architecture:** Папка `web/` (Vite + React 19 + TypeScript strict) собирается в `client/next/`, Express отдаёт её на `/new` с fallback на `index.html`. API не меняется, кроме добавлений из раздела 7 спеки. Бизнес-логика (прогресс, валидация) — в `web/src/domain/` без React; серверная валидация — в `src/services/surveyValidation.js`; обе стороны гоняют одни фикстуры из `test/fixtures/surveyValidation.json`.

**Tech Stack:** React 19, TypeScript, Vite, react-router 7, @tanstack/react-query 5, CSS Modules, Vitest + @testing-library/react + jsdom; сервер — Express 5, libsql, `node --test`.

**Spec:** `docs/superpowers/specs/2026-09-22-react-stage0-1-design.md` (исходное ТЗ: `docs/ТЗ_переписывание_интерфейса_2026_09_22.md` в ветке `redesign/survey-cleanup`).

## Global Constraints

- Node 26, npm 11. Сервер на Vercel serverless (`api/index.js`), функция замирает после ответа — вся работа до `res.json`.
- Сборка кладётся в `client/next/` (в `.gitignore`), исходники — только в `web/`.
- Файл > 400 строк — разбить. Разметка только JSX. Без веб-шрифтов, без Tailwind.
- Тёмная тема через `data-theme` на `<html>`, выставляется до первой отрисовки.
- Телефон 375 px — основной сценарий; интерактивные элементы ≥ 44 px.
- Все тексты интерфейса — по-русски, подписи короче содержания (ТЗ раздел 10).
- Ответы сервера: `{ ok: true, ... }` либо `{ ok: false, error }`; клиент никогда не подменяет текст ошибки сервера.
- Коммиты локальные, на прод не пушить. Pre-commit хук сам бампит версию и добавляет файлы версии в коммит — это нормально.
- Существующие серверные тесты (`npm test`) должны оставаться зелёными после каждой задачи.
- Схема БД: только добавления (новая таблица `position_no_comparison`, колонка `user_capabilities.expires_at`), миграции данных нет.

```ts
export type Theme = 'light' | 'dark';
const KEY = 'theme';
export function getTheme(): Theme {
  const t = document.documentElement.getAttribute('data-theme');
  return t === 'dark' ? 'dark' : 'light';
}
export function setTheme(t: Theme) {
  document.documentElement.setAttribute('data-theme', t);
  try { localStorage.setItem(KEY, t); } catch { /* приватный режим */ }
}
export function toggleTheme(): Theme {
  const next: Theme = getTheme() === 'dark' ? 'light' : 'dark';
  setTheme(next);
  return next;
}
```

`Sheet.tsx`:
```tsx
import { useEffect, useRef } from 'react';
import s from './Sheet.module.css';
type Props = { open: boolean; onClose: () => void; title: string; children: React.ReactNode; footer?: React.ReactNode };
export function Sheet({ open, onClose, title, children, footer }: Props) {
  const ref = useRef<HTMLDivElement>(null);
  useEffect(() => {
    if (!open) return;
    const onKey = (e: KeyboardEvent) => { if (e.key === 'Escape') onClose(); };
    document.addEventListener('keydown', onKey);
    ref.current?.focus();
    return () => document.removeEventListener('keydown', onKey);
  }, [open, onClose]);
  if (!open) return null;
  return (
    <div className={s.backdrop} onClick={onClose}>
      <div ref={ref} tabIndex={-1} role="dialog" aria-modal="true" aria-label={title} className={s.panel} onClick={e => e.stopPropagation()}>
        <div className={s.head}><strong>{title}</strong><button type="button" className={s.close} aria-label="Закрыть" onClick={onClose}>×</button></div>
        <div className={s.content}>{children}</div>
        {footer && <div className={s.foot}>{footer}</div>}
      </div>
    </div>
  );
}
```

```tsx
import { createContext, useCallback, useContext, useState } from 'react';
import s from './Toast.module.css';
type Tone = 'info' | 'ok' | 'error';
type Item = { id: number; text: string; tone: Tone };
const Ctx = createContext<{ show: (text: string, tone?: Tone) => void }>({ show: () => {} });
export function ToastHost({ children }: { children: React.ReactNode }) {
  const [items, setItems] = useState<Item[]>([]);
  const show = useCallback((text: string, tone: Tone = 'info') => {
    const id = Date.now() + Math.random();
    setItems(list => [...list, { id, text, tone }]);
    setTimeout(() => setItems(list => list.filter(i => i.id !== id)), 4000);
  }, []);
  return (
    <Ctx.Provider value={{ show }}>
      {children}
      <div className={s.host} role="status" aria-live="polite">
        {items.map(i => <div key={i.id} className={[s.toast, s[i.tone]].join(' ')}>{i.text}</div>)}
      </div>
    </Ctx.Provider>
  );
}
export const useToast = () => useContext(Ctx);
```

```ts
export class ApiError extends Error {
  constructor(public status: number, message: string, public fields?: Record<string, string>) { super(message); }
}
let onUnauthorized: () => void = () => {};
export function setUnauthorizedHandler(fn: () => void) { onUnauthorized = fn; }

export async function request<T>(path: string, body?: unknown, init: { method?: 'GET' | 'POST' } = {}): Promise<T> {
  const method = init.method ?? (body === undefined ? 'GET' : 'POST');
  const res = await fetch('/api' + path, {
    method,
    credentials: 'include',
    headers: body === undefined ? undefined : { 'Content-Type': 'application/json' },
    body: body === undefined ? undefined : JSON.stringify(body)
  });
  let data: any = null;
  try { data = await res.json(); } catch { /* пустой ответ */ }
  if (res.status === 401) { onUnauthorized(); throw new ApiError(401, data?.message || data?.error || 'Требуется вход'); }
  if (!res.ok || !data || data.ok === false) {
    throw new ApiError(res.status, data?.message || data?.error || 'Ошибка сервера', data?.fields);
  }
  return data as T;
}
```

```tsx
import { createContext, useCallback, useContext, useEffect, useState } from 'react';
import { authApi } from '../../api/auth';
import { setUnauthorizedHandler } from '../../api/client';
import type { SessionData } from '../../api/contract';

type State = { status: 'loading' | 'anon' | 'authed'; data?: SessionData };
const Ctx = createContext<State & { refresh: () => Promise<void>; logout: () => Promise<void>; setData: (d: SessionData) => void }>(null!);

export function SessionProvider({ children }: { children: React.ReactNode }) {
  const [state, setState] = useState<State>({ status: 'loading' });
  const refresh = useCallback(async () => {
    try { const r = await authApi.resume(); setState({ status: 'authed', data: r.data }); }
    catch { setState({ status: 'anon' }); }
  }, []);
  const logout = useCallback(async () => { try { await authApi.logout(); } finally { setState({ status: 'anon' }); } }, []);
  useEffect(() => { setUnauthorizedHandler(() => setState({ status: 'anon' })); void refresh(); }, [refresh]);
  return <Ctx.Provider value={{ ...state, refresh, logout, setData: d => setState({ status: 'authed', data: d }) }}>{children}</Ctx.Provider>;
}
export const useSession = () => useContext(Ctx);
```

```js
'use strict';
/**
 * Единый контракт валидации анкеты (ТЗ раздел 11). Клиент повторяет те же
 * правила в web/src/domain/validation.ts; оба гоняют test/fixtures/surveyValidation.json.
 * Сервер — источник истины.
 */
const MAX_MONEY = 1e9;

function trim(v) { return String(v == null ? '' : v).trim(); }

/** '12 000,50' → 12000.5; '' → 0; мусор → null */
function parseMoney(raw) {
  const s = trim(raw).replace(/\s+/g, '').replace(',', '.');
  if (s === '') return 0;
  if (!/^-?\d+(\.\d+)?$/.test(s)) return null;
  return Number(s);
}

/** Начатая запись — где заполнено хоть что-то, кроме ключа (компания/должность) и валюты/периода по умолчанию. */
function isStarted(item) {
  const keys = ['payFrom', 'payTo', 'schedule', 'bonHas', 'source', 'trust', 'benefits', 'extra', 'note', 'posTheir'];
  if (keys.some(k => Array.isArray(item[k]) ? item[k].length > 0 : trim(item[k]) !== '')) return true;
  return Array.isArray(item.bonuses) && item.bonuses.some(b => b && (trim(b.type) || trim(b.size) || trim(b.per)));
}

function validateSurveyItem(item, refs) {
  const fields = {};
  const value = {
    company: trim(item.company), posOur: trim(item.posOur), posTheir: trim(item.posTheir), grade: trim(item.grade),
    cur: trim(item.cur || 'сомони').toLowerCase(), payPer: trim(item.payPer || 'в месяц').toLowerCase(),
    schedule: trim(item.schedule), bonHas: trim(item.bonHas), source: trim(item.source), trust: trim(item.trust),
    extra: trim(item.extra), note: trim(item.note), benefits: Array.isArray(item.benefits) ? item.benefits.map(trim).filter(Boolean) : [],
    bonuses: Array.isArray(item.bonuses) ? item.bonuses : [], payFrom: 0, payTo: 0
  };
  if (!value.company) fields.company = 'Укажите компанию';
  if (!value.posOur) fields.posOur = 'Укажите должность';

  for (const k of ['payFrom', 'payTo']) {
    const n = parseMoney(item[k]);
    if (n === null) fields[k] = 'Только число';
    else if (n < 0) fields[k] = 'Не может быть отрицательным';
    else if (n > MAX_MONEY) fields[k] = 'Слишком большое число';
    else value[k] = n;
  }
  if (!fields.payFrom && !fields.payTo && value.payFrom > 0 && value.payTo > 0 && value.payFrom > value.payTo) {
    fields.payTo = '«До» не может быть меньше «от»';
  }
  if (!refs.currencies.includes(value.cur)) fields.cur = 'Валюта не из справочника';
  if (!refs.payPeriods.includes(value.payPer)) fields.payPer = 'Период выплаты не из справочника';

  if (isStarted(item)) {
    if (!value.schedule) fields.schedule = 'Укажите график работы';
    if (!value.bonHas) fields.bonHas = 'Укажите, есть ли премии';
    if (!value.source) fields.source = 'Укажите источник данных';
    if (!value.trust) fields.trust = 'Укажите надёжность';
  }

  const keys = Object.keys(fields);
  if (keys.length) return { ok: false, error: fields[keys[0]], fields };
  return { ok: true, value };
}

module.exports = { validateSurveyItem, isStarted, parseMoney, MAX_MONEY };
```

```js
const normPosKey = v => String(v == null ? '' : v).toLowerCase().replace(/ё/g, 'е').replace(/\s+/g, ' ').trim();

/** Компания «заполнена», если есть хоть что-то существенное (ТЗ 3.4). */
function surveyHasSubstance(s) {
  if (Number(s.payFrom) > 0 || Number(s.payTo) > 0) return true;
  if (Array.isArray(s.bonuses) && s.bonuses.some(b => b && String(b.size || '').trim())) return true;
  if (Array.isArray(s.benefits) ? s.benefits.length > 0 : String(s.benefits || '').trim()) return true;
  return !!(String(s.extra || '').trim() || String(s.note || '').trim());
}

/** Прогресс подразделения по должностям: решено / всего (ТЗ 3.4). Чистая функция. */
function positionProgress({ positions, surveys, noComparison }) {
  const decidedKeys = new Set();
  (surveys || []).forEach(s => { if (surveyHasSubstance(s)) decidedKeys.add(normPosKey(s.posOur)); });
  (noComparison || []).forEach(p => decidedKeys.add(normPosKey(p)));
  const total = (positions || []).length;
  const decided = (positions || []).filter(p => decidedKeys.has(normPosKey(p))).length;
  return { decided, total };
}
```

- [ ] **Step 2: `useUnitData`**

```ts
export function useUnitData(unit: string, periodId: number | null) {
  const { data: session } = useSession();
  const q1 = useQuery({ queryKey: ['survey', unit, periodId], queryFn: () => surveyApi.forPeriod(unit, periodId) });
  const q2 = useQuery({ queryKey: ['selections', unit, periodId], queryFn: () => surveyApi.selections(unit, periodId) });
  const div = session?.allUnits.find(d => d.unit === unit);
  const groupKey = div?.group_key ?? '';
  const groupUnits = groupKey ? (session?.allUnits.filter(d => d.group_key === groupKey).map(d => d.unit) ?? []) : [];
  return {
    isLoading: q1.isLoading || q2.isLoading, error: q1.error ?? q2.error,
    positions: session?.positionsByUnit[unit] ?? [],
    surveys: q1.data?.surveys ?? [], progress: q1.data?.progress ?? { decided: 0, total: 0 },
    selections: q2.data?.selections ?? {}, noComparison: new Set(q2.data?.noComparison ?? []),
    groupKey, groupUnits
  };
}
```
