> зачёркнутой, только как история.
>
> Как есть сейчас:
> - **Бэкенд:** Node.js + Express (`src/server.js`, `src/routes/api.js`,
>   `src/controllers/*`). Деплой — Render (авто-деплой ветки `main`).
> - **База данных:** Turso (libsql) — SQLite-совместимая, доступ через
>   `@libsql/client` (`src/db/database.js`). Схема — `src/db/schema.sql`,
>   идемпотентные миграции при старте — `src/db/migrate.js`.
> - **Фронтенд:** один статический SPA — `public/index.html` (рендер строками)
>   + `public/style.css`. Отдаётся тем же Express (`express.static`).
> - **Telegram-бот:** `node-telegram-bot-api`, webhook на `/api/telegram/webhook`
>   (проверка секретным заголовком, без JWT). Cloudflare Worker-релей больше
>   не нужен — Render принимает вебхук напрямую.
> - **Авторизация:** JWT (`jsonwebtoken`), скользящая сессия 7 дней,
>   `/api/auth/resume` продлевает. Хэш паролей — bcrypt (cost 12).
> - **Модуль бенчмаркинга** (мультиисточниковые вилки): `src/services/benchmark*.js`,
>   `src/worker.js` (Cloudflare Worker для внешней раздачи), таблицы `benchmark_*`
>   в схеме.
>
> Локальная разработка: `.env` из `.env.example`; при недоступности Turso —
> `TURSO_DATABASE_URL=file:data/local.db` и наполнение через
> `scratch/setup-local-db.js` (в репозитории не хранится).

## 📌 1. Назначение и цель системы
Единая адаптивная веб-система (**Telegram Mini App + Web-интерфейс**) для сбора, мониторинга и анализа заработных плат, бонусов, структуры компенсаций и условий труда компаний-конкурентов по всем подразделениям и штатным должностям ГК «Фаровон».

## 🎨 3. Архитектура интерфейса и UX/UI стандарты

### 3.1. Анимированный ролевой онбординг (Interactive Tour)
* При первом входе система определяет роль пользователя и запускает интерактивный пошаговый тур с подсветкой элементов.
* Пользователю наглядно демонстрируется:
  1. Где находятся его подразделения.
  2. Как выбрать компанию-конкурента слева.
  3. Как выбрать должность справа.
  4. Как быстро заполнить карточку оклада и бонусов.

### 3.2. Компоновка Split-View
* **Левая панель:** Список компаний-конкурентов по выбранному направлению со статусами охвата.
* **Правая панель:** Штатные должности подразделения. Напротив каждой должности цветной бейдж статуса по выбранной компании (серый — не заполнено, зелёный — заполнено).
* **Фокусная карточка ввода (Modal / Slide-over):**
  * Чёткий фокусный контраст без мутных/серых оттенков.
  * Блоки: *«Оклад от / до»*, *«Налог (Net/Gross)»*, *«Бонусная часть (тип, периодичность, размер)»*, *«Соцпакет / льготы (чипсы быстрого выбора)»*, *«Достоверность источника и комментарий»*.
  * Живой калькулятор: автоматический расчёт медианы, размаха вилки (%) и Total Cash в месяц.

### 3.3. Адаптивность и фиксация вьюпорта (No Layout Shift)
* Полная адаптивность под экраны ноутбуков, планшетов и смартфонов (включая Telegram Mini App).
* Фиксированная высота и границы экрана — запрет случайного горизонтального сдвига страницы.
* Зоны нажатия (Tap Targets) ≥ 44px для комфортной работы с мобильных устройств.
* Подключение `telegram-web-app.js` для разворачивания на полный экран и тактильного отклика (Haptic Feedback).

## ⚡ 4. Архитектура синхронизации и Telegram-бота

> [!WARNING]
> **Устарело.** Ниже — схема на Google Apps Script + Cloudflare Worker.
> Актуальная: `[ Браузер / Telegram Mini App ] → HTTPS+JWT → [ Express на Render ]
> → { Turso (libsql) | Telegram Bot API }`. См. рамку в начале документа.

```
[ Пользователь / Telegram Mini App ] 
                │ (HTTPS)
                ▼
      [ Cloudflare Worker Relay ]
                │ (Follow 302 Redirects)
                ▼
   [ Google Apps Script Web App (/exec) ]
                │
        ┌───────┴───────┐
        ▼               ▼
[ Google Таблица ]  [ Telegram Bot API ]
  (19 листов БД)     (Оповещения & Логин)
```

1. **Мгновенный отклик (Optimistic UI):** Изменения отображаются в интерфейсе мгновенно, фоново синхронизируясь с сервером.
2. **Бесшовная авторизация:** В Telegram Mini App вход осуществляется автоматически по `initData` и номеру телефона; в веб-браузере — по Логину/Паролю с сессией на 30 дней.
3. **Оповещения через Telegram-бот:** HR BP в 1 клик отправляет персонализированные сообщения в Telegram руководителям с прямыми ссылками на форму.
