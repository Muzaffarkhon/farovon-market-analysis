## 🚀 Основные реализованные модули

### 1. Аналитический Дашборд C&B (Руководство и Аналитика)
- **Перцентильный анализ**: расчет `Min`, `P25`, `Median (P50)`, `P75`, `Max` и размаха вилки в `%`.
- **Визуальные Box-Plot шкалы**: наглядное отображение диапазона рынка по каждой должности.
- **Детализация по компаниям**: сравнение окладов и соцпакетов в разрезе конкретных работодателей.
- **Экспорт в CSV**: выгрузка в 1 клик с поддержкой Excel UTF-8 BOM.
- **Воронка охвата**: мониторинг заполнения по HR BP и Дирекциям.
- **Рейтинг льгот**: статистика популярности бенефитов (ДМС, питание, связь, ГСМ) и структуры бонусов.

### 2. Панель Администратора (4 вкладки)
1. 👥 **Пользователи**: создание, редактирование, сброс паролей в 1 клик, блокировка/активация, привязка отделов.
2. 🏢 **Оргструктура (326 отделов)**: оперативное назначение руководителей, ответственных за обзор и HR BP.
3. ⏱️ **Период сбора**: открытие/закрытие кампаний опроса с контролем прав доступа.
4. 🛠️ **Сервис & Журнал**: утилиты нормализации сегментов, проверки связей, пересчета статусов и Audit Log.

### 3. Telegram Mini App & Bot
- Поддержка Telegram WebApp SDK (автоматическая адаптация под тему Telegram).
- Интеграция кнопки меню бота через `@BotFather`.
- Рассылка напоминаний сотрудникам.

## 🛠️ Как запускать проект локально / на сервере

```bash
# 1. Локальный запуск Node.js
npm install
npm run seed     # Сидирование БД из CSV
npm run dev      # Запуск с автоперезагрузкой (http://localhost:3000)

# 2. Запуск через Docker
docker-compose up -d --build
```
