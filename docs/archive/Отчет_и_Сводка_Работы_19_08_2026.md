## 1. Архитектура и перенос Telegram-бота на Cloudflare Worker

### Проблема:
Ранее бот работал на базе механизма опроса (Long Polling) через триггеры Google Apps Script. Это вызывало:
* Задержки ответов до 1–2 минут.
* Конфликты выполнения и лимиты квот GAS.

### Решение:
Бот переведён на событийную модель через **Cloudflare Worker (Webhook Relay)**.

```
[ Telegram Серверы ] 
        │ (мгновенный Webhook HTTPS POST)
        ▼
[ Cloudflare Worker ] ── (прокси с автоматическим следованием 302 Redirect)
        │
        ▼
[ Google Apps Script Web App (/exec) ] ── (doPost: обработка команд и выдача паролей)
        │
        ▼
[ Google Таблица (БД) ]
```

* **URL Cloudflare Worker:** `https://farovon-tg-relay.muzaffarkhonr.workers.dev`
* **Код Worker:** сохранён в `cloudflare_worker_tg_relay.js`.
* **Статус:** Вебхук успешно привязан к Telegram Bot API, старые поллинг-триггеры удалены, задержка сокращена до <1 секунды.

## 3. Очистка мусорных данных в листе «Справочник»

### Выявленная проблема:
В столбце `L (Подразделение)` на листе «Справочник» было обнаружено **266 строк с мусором**, где к названиям подразделений механически приклеились ФИО руководителей и HR BP.

*Пример ошибки:*
* ❌ `Департамент автоматизации и информационных технологий Бобохонов Аслидин Муталлибович Каримов Дилшодчон Зафарчонович`
* ✅ `Департамент автоматизации и информационных технологий`

### Причина и решение:
Лист «Справочник» является автогенерируемым. При запуске функции `настроитьСистему()` (или пункта меню **«Обзор рынка → Проверка → Настроить систему»**) справочник пересобирается из чистых исходных данных листа «Подразделения».

## 5. Обновления в коде (Code.gs)

В основной скрипт проекта внесены следующие модули:

1. **`исправитьСегментыКомпаний()`**:
   * Сканирует листы «Конкуренты» и «Справочник компаний».
   * Корректирует сегменты АНТ, Озода косметикс и профильных конкурентов.
   * Унифицирует дублирующиеся названия.
   * Каскадно обновляет сводный справочник.
2. **`починитьРасхождения()`**:
   * Автоматически сопоставляет строки между листами «Конкуренты», «Подразделения» и «Справочник должностей».
   * Устраняет битые ссылки и сироты.
3. **Меню таблицы (`onOpen`)**:
   * Добавлены пункты:
     * *«Починить расхождения в Связях»*
     * *«Исправить сегменты компаний»*
     * *«Привязать Webhook к Cloudflare»*

## 6. Пошаговая инструкция для применения изменений

1. Откройте файл [Code.gs](file:///c:/Users/USER/Downloads/Telegram%20Desktop/Разработка%20документов/C&B/Разработка/Code.gs).
2. Скопируйте всё его содержимое (`Ctrl + A`, `Ctrl + C`).
3. В Google Таблице перейдите: **Расширения ➔ Apps Script**.
4. Вставьте код в редактор и сохраните (`Ctrl + S`).
5. Для применения исправлений сегментов и справочника:
   * Выберите в выпадающем списке редактора функцию **`исправитьСегментыКомпаний`** и нажмите **Выполнить (▶️)**.
   * Либо в меню таблицы выберите: **Обзор рынка ➔ Проверка ➔ Исправить сегменты компаний**.
6. При необходимости создайте новую версию веб-приложения:
   * **Развернуть ➔ Управление развёртываниями ➔ Изменить (карандаш) ➔ Новая версия ➔ Развернуть**.
