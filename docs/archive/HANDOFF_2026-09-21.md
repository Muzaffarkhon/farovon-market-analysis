## 5. Грабли этой сессии (важно для будущих правок)

1. **Мёрж `main` в ветку дал один конфликт** — в `updateCardCompleteness` (`client/app.js`): в `main` там появился вызов `updateBatchProgress()` (счётчик «Оклад указан N из M» + баннер «от > до»), у нас — обновление строки списка и раскрытие блоков. Оставлено всё вместе. Разметку счётчика и баннера git удачно влил внутрь нашей новой `renderSheetContent` — после мержа они работают, проверено в браузере. Свой дублирующий счётчик «Заполнено N из M компаний» убрали в пользу пришедшего из `main`.
2. **Закрытый список периодов оплаты на сервере.** В `surveyController.js` есть `ALLOWED_PAY_PERIODS`; всё, чего в нём нет, молча сохраняется как «в месяц». Новый вариант «сдельно (за услугу)» пришлось добавить и туда, и в `ref.payPeriods` (`authController.js`). Поймали только потому, что проверяли сохранение до самой базы, а не по виду формы.
3. **Как читается «Размер» премии.** Число ≤ 100 без единицы измерения считается **процентом от оклада**, больше 100 или с валютой — абсолютной суммой, «1,5 оклада» — в окладах (`parseBonusSize`). То есть «100», введённое как «100 сомони», превратится в «100% оклада». Явного переключателя «% / сумма» нет.
4. **Эвристика ЧТС.** `looksHourly` считает почасовой ставкой любую сумму меньше 1000 — поэтому сдельные ставки (условные 60 сомони за услугу) без отдельной обработки умножались бы на 168 часов. Отсюда `isPieceRate` и исключение таких строк из месячных показателей.
5. **Инерция периода оплаты.** Период подставляется новым компаниям из `S.fillPrefs` и из последней сохранённой записи. Сдельную из этого наследования исключили: одна сдельная запись иначе делала сдельными все следующие компании, а это молча выкидывает оклады из медианы.
6. **LibreOffice в этой среде не открывает pptx** (даже пустой, созданный тут же) — значит, визуальная проверка презентаций рендером недоступна, остаются текстовый дамп (`markitdown`) и проверка структуры (`validate.py`).
7. **Сеть агента** не пускает на `*.vercel.app` — проверить живой сайт можно только руками пользователя. Локальная копия поднимается как обычно: sqlite-файл через `file:`-URL, `migrate()`, `src/db/seed.js`, временный QA-админ, затем Playwright (`playwright-core` + `/opt/pw-browsers/chromium`).
