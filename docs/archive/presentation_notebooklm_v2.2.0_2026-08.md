# СЛАЙД 2. ЧТО ТАКОЕ «ОБЗОР РЫНКА» И ЗАЧЕМ ОНА НУЖНА

## Проблема, которую решает система

До внедрения системы «Обзор рынка» ГК «Фаровон» сталкивалась со следующими вызовами:

- **Ручной сбор данных** — HR Business Partner'ы и руководители вручную заполняли Google-таблицы, которые:
  - Могли быть случайно повреждены любым пользователем
  - Зависали при открытии на 10–15 секунд
  - Не обеспечивали разграничение прав доступа
  - Теряли данные при сбоях скриптов (лимит Google: 6 минут на выполнение)
- **Отсутствие аналитики в реальном времени** — невозможность мгновенно получить перцентильный анализ рынка по конкретной должности
- **Разрозненность данных** — каждое направление вело свою таблицу без единого стандарта
- **Нет контроля исполнения** — руководители не видели, кто заполнил данные, а кто нет

## Решение

«Обзор рынка» — это **единая цифровая платформа**, которая:

✅ Автоматизирует сбор рыночных данных по **326 подразделениям** холдинга  
✅ Рассчитывает **перцентили P25/P50/P75** по каждой должности мгновенно  
✅ Управляет **112 пользователями** с разграничением прав по ролям  
✅ Работает в **браузере и Telegram** без установки дополнительного ПО  
✅ Гарантирует **сохранность данных** в облаке 24/7

# СЛАЙД 3. КТО ПОЛЬЗУЕТСЯ СИСТЕМОЙ (РОЛЕВАЯ МОДЕЛЬ)

Система имеет **5 уровней доступа**, каждый настроен под конкретную задачу:

## 1. Главный Администратор (`admin`)
**Кто это:** IT-специалист или C&B менеджер  
**Что делает:**
- Создаёт и управляет учётными записями всех 112 сотрудников
- Открывает и закрывает периоды сбора данных
- Настраивает оргструктуру 326 подразделений
- Просматривает журнал всех действий в системе (Audit Log)
- Запускает сервисные инструменты (нормализация, импорт)

## 2. C&B Аналитик (`cb`)
**Кто это:** Специалист по компенсациям и льготам  
**Что делает:**
- Получает полную аналитику рынка по всей компании в реальном времени
- Анализирует перцентильные шкалы (Min → P25 → Медиана → P75 → Max)
- Строит сравнительный анализ структуры льгот и бонусов
- Выгружает сводные отчёты в Excel / CSV одним нажатием

## 3. Руководитель Направления / Дивизиона (`dir_head`)
**Кто это:** Руководитель дирекции, директор департамента  
**Что делает:**
- Видит все подразделения своего направления
- Назначает ответственных сотрудников на каждый отдел
- Контролирует прогресс заполнения по своим подразделениям
- Работает **только в пределах своего направления** — данные других дирекций не видны

## 4. HR Business Partner (`hrbp`)
**Кто это:** HR BP, закреплённый за группой подразделений  
**Что делает:**
- Мониторит статус заполнения по своим подразделениям
- Контролирует наличие назначенных ответственных
- Одним кликом отправляет персональные напоминания в Telegram должникам
- Формирует отчёты по воронке охвата своих подразделений

## 5. Ответственный за подразделение (`user`)
**Кто это:** Руководитель отдела или делегированный сотрудник  
**Что делает:**
- Вводит рыночные данные по своим подразделениям через **двухшаговый мастер**:
  - **Шаг 1:** Отбирает компании-конкуренты (с умными подсказками по смежным площадкам)
  - **Шаг 2:** Вводит зарплатные вилки, бонусы и льготы по каждой должности
- Работает **строго в рамках своих подразделений**

# СЛАЙД 4. КАК РАБОТАЕТ СБОР ДАННЫХ — ПОШАГОВАЯ ИНСТРУКЦИЯ

## Для ответственного сотрудника (Руководитель отдела / `user`)

### Вход в систему
1. Перейдите по адресу https://farovon-market-analysis.onrender.com  
   **ИЛИ** откройте Telegram-бот и нажмите «Открыть приложение»
2. Введите логин и пароль, выданные администратором
3. При первом входе система покажет **интерактивный тур** — краткое обучение по интерфейсу

### Шаг 1: Выбор компаний-конкурентов
1. На главном экране выберите **нужное подразделение** (ваши отделы отображаются автоматически)
2. Перейдите во вкладку **«Участники рынка»**
3. Просмотрите предложенный список компаний-конкурентов
4. Для каждой компании отметьте статус:
   - 🟢 **«Актуально»** — компания активна на рынке, данные актуальны
   - 🔴 **«Не актуально»** — компания закрылась или ушла с рынка
   - 🟡 **«Уточнить»** — нужна дополнительная проверка
5. При необходимости добавьте новую компанию через кнопку **«+ Добавить компанию»**

### Шаг 2: Ввод зарплатных данных
1. Перейдите во вкладку **«Данные по рынку»**
2. В левой колонке выберите компанию-конкурента
3. В правой колонке увидите список всех штатных должностей вашего подразделения
4. Для каждой должности нажмите на карточку и заполните:
   - **Оклад «от»** (минимальный) и **«до»** (максимальный) — в сумах
   - **Тип дохода** — Net (на руки) или Gross (до вычета налогов)
   - **Бонусная часть** — тип (KPI, ежемесячный, квартальный, годовой) и размер (%)
   - **Льготы** — ДМС, питание, связь, ГСМ, другие (выбор из готовых чипсов)
   - **Комментарий** и достоверность источника информации
5. После заполнения карточка окрасится в **зелёный цвет** — данные сохранены
6. Система автоматически рассчитает **медиану и размах вилки** прямо в карточке

### Результат
После заполнения всех должностей ваш отдел получает статус **«Заполнено»** — HR BP и руководители сразу это видят.

# СЛАЙД 5. АНАЛИТИЧЕСКИЙ ДАШБОРД C&B

## Что видит C&B Аналитик в режиме реального времени

Дашборд автоматически агрегирует все введённые данные и строит полную картину рынка:

### Перцентильный анализ зарплат
Для каждой должности система рассчитывает:

| Показатель | Значение | Трактовка |
|---|---|---|
| **Min** | Минимальный оклад на рынке | Нижняя граница рынка |
| **P25** | 25-й перцентиль | Ниже рынка — «аутсайдер» |
| **Медиана (P50)** | Середина рынка | Рыночный оклад |
| **P75** | 75-й перцентиль | Выше рынка — «лидер» |
| **Max** | Максимальный оклад | Верхняя граница рынка |
| **Размах (%)** | `((Max - Min) / Min) × 100%` | Волатильность рынка по позиции |

### Box-Plot диаграммы
Визуальное горизонтальное отображение распределения зарплат — позволяет за секунды понять, где находится позиция компании относительно рынка.

### Анализ льгот и бонусов
- Рейтинг популярности льгот: ДМС, питание, связь, ГСМ — по всей выборке
- Структура бонусов: соотношение фиксированной и переменной части у конкурентов

### Воронка охвата
Наглядная диаграмма прогресса заполнения в разрезе:
- По направлениям и дирекциям
- По HR BP
- По каждому отдельному подразделению

### Экспорт данных
Кнопка **«Экспорт в CSV»** — выгрузка всего аналитического среза одним кликом в формате Excel (UTF-8 BOM, корректное отображение кириллицы).

# СЛАЙД 6. TELEGRAM-ИНТЕГРАЦИЯ

## Работа через Telegram — без браузера

Система полностью работает внутри **Telegram Mini App** — специального мини-приложения прямо в мессенджере.

### Как подключить Telegram-аккаунт
1. Войдите в систему через браузер
2. Перейдите в **«Профиль»** → **«Привязать Telegram»**
3. Система сгенерирует персональную ссылку
4. Перейдите по ссылке в Telegram и нажмите **«Поделиться номером телефона»**
5. Аккаунты будут связаны — после этого система доступна прямо в Telegram

### Команды Telegram-бота
- **`/status`** — персональная сводка: сколько подразделений заполнено, сколько нет
- **`/help`** — справка по работе с системой
- **`/unlink`** — отвязать Telegram-аккаунт от учётной записи

### Функция рассылки напоминаний (для HR BP)
HR BP может одним нажатием отправить **персонализированные напоминания в Telegram** всем сотрудникам, которые не заполнили данные:
- «Напомнить назначить» — руководителю департамента, если не назначен ответственный
- «Напомнить заполнить» — конкретному ответственному
- «Оповестить всех должников» — массовая рассылка по всем незаполненным подразделениям

# СЛАЙД 7. ТЕХНИЧЕСКОЕ ОПИСАНИЕ И ИНФРАСТРУКТУРА

## Архитектура системы (для ИТ-руководства)

```
Пользователь (браузер / Telegram)
         │
         ▼  HTTPS
Сервер приложений (Node.js, Render.com, Франкфурт)
         │
         ▼  Облачный протокол LibSQL
База данных (Turso Cloud, AWS Frankfurt) — доступность 99.9%
```

### Технологический стек
| Компонент | Технология | Назначение |
|---|---|---|
| **Сервер** | Node.js 20 + Express 4.21 | Бизнес-логика и API (33 эндпоинта) |
| **База данных** | Turso LibSQL / SQLite | Облачное хранение данных, AWS EU-West |
| **Безопасность** | bcryptjs + JWT | Хеширование паролей, сессии 30 дней |
| **Фронтенд** | HTML5 + Vanilla CSS | SPA-интерфейс без тяжёлых фреймворков |
| **Telegram** | node-telegram-bot-api + WebApp SDK | Мини-приложение и бот |
| **Хостинг** | Render.com | Auto-deploy из GitHub |
| **Мониторинг** | UptimeRobot | Проверка доступности каждые 5 мин |

### Безопасность и надёжность
- **Пароли** хранятся исключительно в виде bcrypt-хешей (10 раундов) — невозможно восстановить в открытом виде
- **JWT-токены** — сессии живут 30 дней, поддержка кириллицы (UTF-8)
- **Аудит-лог** — каждое критическое действие фиксируется с логином, временем и деталями
- **Защита admin** — системного администратора невозможно заблокировать или удалить программно
- **Uptime 100%** — UptimeRobot отслеживает доступность `/health` каждые 5 минут

# СЛАЙД 9. ИСТОРИЯ РАЗРАБОТКИ

## Путь от Google Таблиц до промышленной системы (август 2026 г.)

### Этап 1 — Аудит исходной системы (18–19 августа)
Исходная система работала на Google Apps Script (~8 000 строк кода, 19 листов Google Таблиц). Были выявлены критические ограничения: задержки 10–15 сек, невозможность надёжного разграничения прав, риск потери данных.

### Этап 2 — Создание автономного сервиса (20–21 августа)
Разработан полный стек: Node.js/Express бэкенд, SQLite база данных, аналитический дашборд C&B, JWT-авторизация.

### Этап 3 — Переход на облачную БД (22–23 августа)
Для обеспечения надёжности данных в production перенесены на облачный кластер **Turso LibSQL** (AWS Frankfurt), подключён UptimeRobot, настроен Render.com.

### Этап 4 — Редизайн и финальный релиз (24–25 августа)
Реализовано **36 Pull Request'ов** с масштабными улучшениями:
- Дизайн в стандарте Apple HIG (премиальный интерфейс)
- Полная адаптация под Telegram Mini App
- Система ролей с матрицей возможностей
- Защита данных и аудит-лог
- Смежные группы подразделений (`group_key`)
- Замена эмодзи на 22 профессиональных SVG-иконки

# СЛАЙД 10. РУКОВОДСТВО АДМИНИСТРАТОРА

## Панель Администратора — подробная инструкция

### Управление пользователями
**Раздел:** Боковое меню → «Пользователи»

1. **Создание нового пользователя:**
   - Нажать «+ Добавить пользователя»
   - Заполнить: Логин (транслит ФИО), ФИО, роль, телефон
   - Система автоматически хеширует пароль
   - Закрепить подразделения через поле «Подразделения»

2. **Редактирование пользователя:**
   - Нажать кнопку «✏️» напротив нужного сотрудника
   - Изменить данные и нажать «Сохранить»

3. **Сброс пароля:**
   - Нажать кнопку «🔑» → ввести новый пароль → подтвердить
   - Пользователю нужно будет ввести новый пароль при следующем входе

4. **Архивирование (мягкое удаление):**
   - Нажать «⋮» → «Архивировать»
   - Пользователь переходит в архив (не удаляется из БД)
   - Восстановить можно в любой момент через вкладку «Архив»

5. **Блокировка/Разблокировка:**
   - Переключатель «Активен/Заблокирован» — мгновенно без перезагрузки

### Управление оргструктурой
**Раздел:** Боковое меню → «Оргструктура»

1. Выберите **Направление** (Уровень 2 — дирекция/департамент)
2. Нажмите на **Подразделение** (Уровень 3 — отдел)
3. В открывшейся карточке назначьте:
   - **Руководитель** — `dir_head` (получит доступ ко всему направлению)
   - **Ответственный** — `user` (получит доступ только к этому отделу)
   - **HR BP** — `hrbp` (получит мониторинг этого отдела)
   - **Смежная группа** — `group_key` (объединение однотипных площадок)
4. Нажать «Сохранить изменения»

### Управление периодами сбора
**Раздел:** Боковое меню → «Настройки» → «Периоды»

- **Открыть период** → все ответственные получают возможность вводить/редактировать данные
- **Закрыть период** → данные замораживаются, редактирование заблокировано
- Наименование периода: например, «Обзор рынка Q3 2026»

### Сервисные инструменты
**Раздел:** Боковое меню → «Инструменты»

| Инструмент | Назначение | Когда использовать |
|---|---|---|
| «Нормализация компаний» | Устраняет дублирующиеся записи с разными регистрами | После массового импорта данных |
| «Проверка связей» | Синхронизирует оргструктуру с заполненными данными | При изменении структуры подразделений |
| «Импорт штатного расписания» | Загружает новые должности из CSV-файла | При изменении штатного расписания |
| «Раздать пул компаний» | Распределяет базовый список конкурентов по направлениям | При запуске нового периода |

### Просмотр журнала аудита
**Раздел:** Боковое меню → «Аудит»

- Показывает все критические действия: создание/изменение пользователей, сброс паролей, архивацию, назначения ответственных
- Фильтрация по дате, логину, типу действия

# СЛАЙД 11. ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ (FAQ)

**Q: Как сбросить собственный пароль, если забыл?**  
A: Обратитесь к администратору системы — он сбросит пароль через Панель управления. Самостоятельного сброса через email нет (корпоративный инструмент).

**Q: Могу ли я видеть данные другого направления?**  
A: Нет. Ролевая модель строго изолирует доступ. Руководитель направления видит только свои подразделения. C&B Аналитик видит агрегированные данные всей компании.

**Q: Что произойдёт с данными, если интернет прервётся во время заполнения?**  
A: Система автоматически сохраняет черновики на вашем устройстве. После восстановления соединения данные синхронизируются с сервером.

**Q: Работает ли система на смартфоне?**  
A: Да, полностью. Интерфейс адаптирован под мобильные устройства. Рекомендуется использование через Telegram Mini App для наилучшего мобильного опыта.

**Q: Где хранятся данные? Насколько это безопасно?**  
A: Данные хранятся в облачном кластере Turso LibSQL (AWS Frankfurt, EU-West). Соединение защищено HTTPS. Пароли хранятся в виде bcrypt-хешей и не могут быть восстановлены в открытом виде даже администратором.

**Q: Как добавить новую должность или компанию, которой нет в справочнике?**  
A: Прямо в карточке на Шаге 1 или Шаге 2 нажмите «+ Добавить» и введите новое название. Оно сразу попадёт в общий справочник и станет доступно всем пользователям.

**Q: Как узнать, кто ещё не заполнил данные?**

# ПРИЛОЖЕНИЕ A. ГЛОССАРИЙ

| Термин | Значение |
|---|---|
| **C&B** | Compensation & Benefits — компенсации и льготы |
| **P25 / P50 / P75** | 25-й / 50-й (медиана) / 75-й перцентиль рыночных зарплат |
| **HR BP** | HR Business Partner — партнёр по персоналу, закреплённый за группой подразделений |
| **Вилка** | Диапазон оклада «от» (минимум) до «до» (максимум) |
| **Net** | Зарплата «на руки» (после вычета налогов) |
| **Gross** | Зарплата до вычета налогов (начисление) |
| **Soft Delete** | «Мягкое удаление» — перевод пользователя в архив без физического удаления данных |
| **JWT** | JSON Web Token — защищённый токен авторизации |
| **Telegram Mini App** | Мини-приложение, работающее внутри мессенджера Telegram |
| **Audit Log** | Журнал аудита — хронологическая запись всех действий пользователей |
| **group_key** | Ключ смежной группы — объединение однотипных подразделений (напр., все службы охраны) |
| **UptimeRobot** | Сервис мониторинга доступности — проверяет работоспособность системы каждые 5 минут |
