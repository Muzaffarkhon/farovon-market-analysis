# План реализации: Система «Обзор рынка вознаграждений» (ГК «Фаровон»)

## 📌 Цель
Создать высокопроизводительную, адаптивную систему (**Telegram Mini App + Web**) для сбора, мониторинга и анализа заработных плат, бонусов и условий труда компаний-конкурентов по всем 326 подразделениям и 2965 штатным должностям ГК «Фаровон».

---

## 🎯 1. Структура данных и нормализация

1. **Оргструктура (`Новая_структура.xlsx`)**:
   * 326 подразделений, сгруппированных по 4 уровням иерархии (`Правление` ➔ `Управления/Департаменты` ➔ `Отделы` ➔ `Службы/Участки`).
   * Закрепление 7 HR BP и линейных руководителей.

2. **Штатное расписание (`должности.xlsx`)**:
   * 2965 штатных позиций с автоматической привязкой должностей к 326 подразделениям.
   * Формирование чистого справочника уникальных должностей без дубликатов.

3. **Пользователи и роли (`Пользователи.txt`)**:
   * 106 авторизованных пользователей с четким распределением по 4 ролям:
     1. **Руководитель департамента / дивизиона**
     2. **Руководитель направления / отдела (Ответственный)**
     3. **HR BP** (7 специалистов)
     4. **C&B Specialist** (Фарзона Самадова, Баховаддин Сайдуллоев)
   * *Роль «Гость» полностью исключена.* Автоматический фоллбек: если ответственный не назначен явно, им считается линейный руководитель отдела.

4. **Компании-конкуренты (`Конкуренты_по_подразделениям_ОБЩИЙ.xlsx`)**:
   * Сводный справочник конкурентов с очищенными сегментами (АНТ ➔ `Телеком`, Озода косметикс ➔ `Пр-во/текстиль`, удаление дублей).

---

## 🎨 2. Разработка веб-интерфейса (`Index.html`)

1. **Анимированный ролевой онбординг**:
   * Интерактивный гид при первом входе, подсвечивающий шаги в зависимости от роли (как выбрать конкурента, как выбрать должность, как заполнить карточку).
2. **Компоновка Split-View**:
   * **Слева**: Список компаний-конкурентов с фильтрами и статусом охвата.
   * **Справа**: Список штатных должностей отдела с цветовыми индикаторами (серый — не заполнено, зелёный — заполнено).
3. **Фокусная карточка ввода (Slide-over / Modal)**:
   * Высококонтрастный дизайн без блеклых серых оттенков.
   * Живой калькулятор: автоматический расчёт медианы, размаха вилки (%) и Total Cash/месяц.
   * Удобные чипсы выбора льгот и параметров бонусов.
4. **Адаптивность и фиксация вьюпорта (No Layout Shift)**:
   * Фиксированные границы экрана (без горизонтального сдвига на мобильных).
   * Кликабельные зоны (Tap Targets) ≥ 44px.
   * Подключение `telegram-web-app.js` для разворачивания на полный экран в Telegram Mini App.
5. **Инструменты HR BP и C&B**:
   * Для HR BP: Кнопки точечных и массовых напоминаний через Telegram-бота («Напомнить назначить», «Напомнить заполнить», «Оповестить всех должников»).
   * Для C&B: Аналитический дашборд с воронкой сбора данных, графиками рыночных вилок (Мин/Медиана/Макс) и экспортом в Excel в 1 клик.

---

## ⚡ 3. Бэкенд и синхронизация (`Code.gs`)

1. **Делегирование в реальном времени**:
   * API для назначения ответственного руководителем департамента прямо из Web App.
2. **Бесшовная авторизация**:
   * Автоматический вход по `initData` в Telegram Mini App и по логину/паролю с 30-дневной сессией в браузере.
3. **Оптимизация производительности**:
   * Пакетная обработка данных в памяти без риска 6-минутных таймаутов GAS.
   * Мгновенный отклик интерфейса (Optimistic UI) с фоновой синхронизацией.
