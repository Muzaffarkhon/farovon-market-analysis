# 📋 Сценарии тестирования: Тестировщик №2 (Руководитель направления)

* **Роль:** `dir_head` / `head` (Руководитель дирекции / подразделения)
* **Цель:** Проверка закрепления отделов, назначения ответственных сотрудников, структуры штатного расписания и контроля прогресса.
* **Ссылка для входа:** `http://localhost:3000` (или рабочий URL Render)

---

## 🔹 Сценарий 2.1: Назначение ответственных по подчиненным отделам

### Предусловие:
Руководитель вошёл в систему под своей учётной записью (`dir_head`).

### Шаги:
1. На главной странице перейдите в экран **«Назначить ответственных»**.
2. В таблице подразделений своего направления найдите отдел, требующий назначения.
3. В выпадающем списке выберите ответственного сотрудника (`resp`) и закреплённого `hrbp`.
4. Нажмите кнопку **«Сохранить назначения»**.

### Ожидаемый результат:
* [ ] Руководитель видит только подразделения своего направления (без чужих дирекций).
* [ ] Назначения сохраняются без ошибок, появляется подтверждающее сообщение.
* [ ] Назначенный сотрудник сразу видит это подразделение в своём личном кабинете.

---

## 🔹 Сценарий 2.2: Вход в подразделение и проверка штатки (Шаг 2)

### Шаги:
1. Выберите доступное подразделение из списка на главной странице и откройте его.
2. Проверьте Шаг 1 («Участники рынка»).
3. Переключитесь на вкладку **«Шаг 2. Данные по рынку»**.
4. Проверьте список должностей:
   * Отображаются именно должности штатного расписания этого отдела.
   * Если штатка не загружена, доступна кнопка добавления должности.
5. Раскройте карточку должности — проверьте матрицу компаний по данной должности.

### Ожидаемый результат:
* [ ] Переключение между Шагом 1 и Шагом 2 происходит мгновенно без перезагрузки экрана.
* [ ] Список должностей соответствует штатному расписанию отдела.
* [ ] Матрица компаний отображается компактно и понятно.

---

## 🔹 Сценарий 2.3: Мониторинг прогресса сбора данных по направлению

### Шаги:
1. Вернитесь на главную страницу (кнопка «Назад» в левом верхнем углу).
2. Проверьте сводную карточку своего направления:
   * Процент выполнения сбора.
   * Количество заполненных, находящихся в процессе и не начатых подразделений.
3. Проверьте цветовую индикацию статусов отделов (зелёный — заполнено, жёлтый — в процессе, серый — не начато).

### Ожидаемый результат:
* [ ] Прогресс-бары и счётчики точно отражают реальное количество проверенных компаний и анкет.
* [ ] Статусы обновляются в реальном времени после сохранения данных респондентами.
