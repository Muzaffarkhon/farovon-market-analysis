# 📋 Сценарии тестирования: Тестировщик №1 (Администратор C&B)

* **Роль:** `admin` (Полный доступ к системе)
* **Цель:** Проверка сервисных утилит, каскадного снятия блокировок, управления пользователями, справочников и конструктора прав.
* **Ссылка для входа:** `http://localhost:3000` (или рабочий URL Render)

---

## 🔹 Сценарий 1.1: Управление и снятие блокировок записей

### Предусловие:
Администратор вошёл в систему под учётной записью с ролью `admin`.

### Шаги:
1. Перейдите в раздел **«Сервисные утилиты»** (вкладка в панели администрирования).
2. Найдите блок **«Управление блокировками записей»**.
3. Нажмите кнопку **«Выборочно по ролям / авторам…»**.
4. В открывшемся модальном окне проверьте отображение пользователей, удерживающих записи (количество компаний и анкет).
5. Протестируйте действие **«Снять с администраторов»** или снимите блокировку с конкретного пользователя кнопкой «Снять».
6. Закройте окно и нажмите **«Снять со всех (1 клик)»** для полной каскадной разблокировки.

### Ожидаемый результат:
* [ ] Модальное окно корректно показывает список заблокированных записей с бейджами ролей.
* [ ] Всплывает зелёный toast с отчётом о количестве снятых блокировок.
* [ ] У ответственных сотрудников на карточках пропадают значки замков 🔒, редактирование становится доступным.

## 🔹 Сценарий 1.2: Единые таблицы справочников и оргструктуры

### Шаги:
1. Откройте раздел **«Справочники»** → вкладку **«Компании»**.
2. Добавьте новую компанию (укажите название, сегмент, регион и привязку к направлению).
3. Проверьте поведение таблицы:
   * Таблица занимает высоту экрана до низа страницы.
   * Заголовок остаётся на месте, строки плавно скроллятся.
4. Перейдите в разделы **«Пользователи»** и **«Оргструктура»**.
5. Убедитесь, что таблицы пользователей и отделов открываются мгновенно и скроллятся в таком же едином дизайне.

### Ожидаемый результат:
* [ ] Новая компания успешно создаётся и появляется в списке.
* [ ] Таблицы во всех разделах («Справочники», «Пользователи», «Оргструктура») единообразны по высоте и стилю.
* [ ] Загрузка списков происходит без задержек.

## 🔹 Сценарий 1.3: Конструктор ролей и журнал аудита

### Шаги:
1. Откройте вкладку **«Роли и доступы»**.
2. Для роли `hrbp` временно переключите право (например, «Просмотр журнала аудита»).
3. Нажмите **«Сохранить права»**.
4. Перейдите во вкладку **«Аудит»** и проверьте последние записи.
5. Воспользуйтесь поиском по журналу аудита (введите логин или действие).

### Ожидаемый результат:
* [ ] Права сохраняются в базе данных.
* [ ] Действие фиксируется в журнале аудита с точным временем и логином администратора.
* [ ] Поиск по аудиту фильтрует события без перезагрузки страницы.
