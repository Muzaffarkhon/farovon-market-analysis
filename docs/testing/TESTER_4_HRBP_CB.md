# 📋 Сценарии тестирования: Тестировщик №4 (C&B Аналитик / HR BP)

* **Роль:** `cb` / `hrbp` (C&B Аналитик, HR Бизнес-партнёр)
* **Цель:** Проверка аналитического дашборда, фильтрации по направлениям, формул вилок зарплат и выгрузки отчётов.
* **Ссылка для входа:** `http://localhost:3000` (или рабочий URL Render)

---

## 🔹 Сценарий 4.1: Быстрая фильтрация и поиск на Дашборде C&B

### Предусловие:
Пользователь вошёл в систему под учётной записью с ролью `cb` или `hrbp`.

### Шаги:
1. Перейдите в раздел **«Дашборд C&B»** (или вкладку HR BP).
2. Выберите фильтр по конкретному направлению (Дирекции) в верхнем селекторе.
3. Введите название должности в поисковой строке (например, «Экономист», «Менеджер», «Водитель»).
4. Оцените скорость пересчёта сводной аналитики (благодаря новым индексам и параллельным запросам отклик должен быть практически мгновенным).

### Ожидаемый результат:
* [ ] Фильтрация отрабатывает без задержек и подвисаний.
* [ ] Общее количество записей, средние и медианные показатели соответствуют выбранному срезу данных.

---

## 🔹 Сценарий 4.2: Проверка математики C&B (Медианы, квартили, размах вилки)

### Шаги:
1. Найдите должность, по которой внесены данные от нескольких компаний.
2. Разверните детальную карточку должности.
3. Проверьте ключевые метрики:
   * **Мин (TJS)** — минимальный зафиксированный оклад.
   * **25% перцентиль (P25)** — нижняя четверть рынка.
   * **Медиана (P50)** — центральное рыночное значение.
   * **75% перцентиль (P75)** — верхняя четверть рынка.
   * **Макс (TJS)** — максимальный оклад.
   * **Размах вилки (%)** — отношение ширины вилки к минимуму `((Макс - Мин) / Мин * 100%)`.
4. Убедитесь, что нет ошибок `NaN`, деления на 0 или некорректных округлений.

### Ожидаемый результат:
* [ ] Все показатели рассчитаны корректно по правилам статистики C&B.
* [ ] Числа отформатированы с разделением тысяч (например, `8 500 TJS`).
* [ ] Размах вилки отображается с понятным знаком процента.

---

## 🔹 Сценарий 4.3: Экспорт сводного отчёта в Excel / CSV

### Шаги:
1. На дашборде нажмите кнопку **«Экспорт в CSV»** в правом верхнем углу.
2. Сохраните сформированный файл и откройте его в Microsoft Excel (или Google Таблицах).
3. Проверьте содержимое файла:
   * Кодировка кириллицы (текст читается без «кракозябр»).
   * Корректность колонок (Должность, Кол-во записей, Мин, P25, Медиана, P75, Макс, Среднее, Размах).

### Ожидаемый результат:
* [ ] Файл скачивается моментально.
* [ ] Текст на русском языке отображается чисто (UTF-8 с BOM).
* [ ] Цифровые данные легко поддаются дальнейшей формульной обработке в Excel.
