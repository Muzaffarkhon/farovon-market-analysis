# 📋 Сценарии тестирования: Тестировщик №3 (Ответственный сотрудник / Респондент)

* **Роль:** `user` / `resp` (Ответственный за заполнение данных подразделения)
* **Цель:** Проверка прохождения Шага 1 и Шага 2, массовой отметки актуальности, валидации окладов и отправки данных.
* **Ссылка для входа:** `http://localhost:3000` (или рабочий URL Render)

---

## 🔹 Сценарий 3.1: Шаг 1 — Поиск и массовая отметка участников рынка

### Предусловие:
Сотрудник вошёл под своей учётной записью и открыл назначенное подразделение.

### Шаги:
1. Обратите внимание на верхнюю панель:
   * Слева: вкладки **«Шаг 1. Участники рынка»** и **«Шаг 2. Данные по рынку»**.
   * Справа: поиск `«Поиск компании в списке…»`, счётчик компаний и кнопка `«Отметить все «Актуально»`.
   * *Убедитесь, что внутри карточки дублирующих кнопок и поиска нет.*
2. Протестируйте поиск: введите 2–3 буквы названия компании.
3. Нажмите кнопку **«Отметить все «Актуально»** в верхней панели.
4. Для одной из компаний нажмите на статус и выберите **«Требует уточнения»**, добавив короткую заметку.
5. Нажмите кнопку **«Сохранить»** внизу экрана.

### Ожидаемый результат:
* [ ] Элементы управления не дублируются, интерфейс чистый и аккуратный.
* [ ] Поиск мгновенно фильтрует карточки компаний.
* [ ] Кнопка отмечает все компании как «Актуально», бейдж прогресса пересчитывается (например, `9/10, ?1 на уточнении`).
* [ ] Данные успешно сохраняются, всплывает подтверждающий toast.

---

## 🔹 Сценарий 3.2: Шаг 2 — Заполнение анкет и защита от ошибок ввода

### Шаги:
1. Нажмите внизу кнопку **«Перейти к Шагу 2: Заполнение данных по рынку →»** (или переключите вкладку вверху).
2. Раскройте карточку должности.
3. **Тест на ошибку валидации:**
   * Введите «Оклад от» = `12 000`, а «Оклад до» = `6 000`.
   * Нажмите «Сохранить черновик».
   * *Убедитесь, что система заблокировала сохранение и показала понятное предупреждение.*
4. **Корректный ввод:**
   * Исправьте значения: «Оклад от» = `6 000`, «Оклад до» = `12 000`.
   * Выберите валюту (сомони), тип бонуса (например, «Квартальный KPI») и периодичность.
   * Отметьте дополнительные льготы (питание, связь, транспорт).
5. Нажмите **«Сохранить черновик»**.

### Ожидаемый результат:
* [ ] Валидатор не пропускает ошибку `от > до`.
* [ ] Корректные данные сохраняются мгновенно без зависаний.
* [ ] Прогресс-бар заполнения анкет в правом верхнем углу увеличивается.

---

## 🔹 Сценарий 3.3: Комментарий по подразделению и финальная отправка

### Шаги:
1. Заполните данные по ключевым должностям подразделения.
2. В поле **«Комментарий по подразделению»** введите текстовое примечание (например: *«Дефицит опытных специалистов на рынке Согда»*).
3. Нажмите кнопку **«Отправить данные»** внизу экрана.
4. В модальном окне подтвердите отправку.

### Ожидаемый результат:
* [ ] Подразделение переходит в статус «Заполнено / Отправлено».
* [ ] Фиксируется точное время отправки.
* [ ] Внесённый комментарий сохраняется и отображается руководителю и C&B аналитику.
