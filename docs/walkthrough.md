## 🚀 Пошаговое руководство по развёртыванию

### Шаг 1: Обновление кода в Google Apps Script
1. Откройте Google Таблицу ➔ **Расширения ➔ Apps Script**.
2. В файле **`Code.gs`** замените весь текст на содержимое файла [Code.gs](file:///C:/Users/USER/Desktop/Обзор_рынка_Фаровон/Code.gs).
3. В файле **`Index.html`** замените весь текст на содержимое файла [Index.html](file:///C:/Users/USER/Desktop/Обзор_рынка_Фаровон/Index.html).
4. Нажмите **Сохранить** (`Ctrl + S`).

### Шаг 2: Создание новой версии развёртывания
1. В правом верхнем углу редактора Apps Script нажмите: **Развернуть ➔ Управление развёртываниями**.
2. Нажмите на значок **карандаша (Редактировать)**.
3. В поле «Версия» выберите **Новая версия**.
4. Нажмите **Развернуть** (Deploy).

### Шаг 3: Синхронизация данных в таблице
1. Обновите страницу Google Таблицы (`F5`).
2. В верхнем меню выберите: **«Обзор рынка ➔ Проверка ➔ Настроить систему»** (или *«Синхронизировать всё»*).
3. Примените исправление сегментов: **«Обзор рынка ➔ Проверка ➔ Исправить сегменты компаний»**.
